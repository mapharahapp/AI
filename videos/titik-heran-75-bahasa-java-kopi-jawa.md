## 1. Topik yang dipilih

**Bahasa pemrograman Java (Sun Microsystems, dirilis Mei 1995) awalnya bernama Oak (dari pohon ek di luar kantor James Gosling), lalu Green, lalu Java "dari kopi Java, jenis kopi dari Indonesia" (Wikipedia). Kisah dari tim pembuatnya (JavaWorld 1996, dimuat ulang InfoWorld): pengacara melarang "Oak" karena sudah dipakai Oak Technologies; dalam sesi curah gagasan, Chris Warth "sedang minum secangkir Peet's Java" saat mengusulkan "Java"; keputusan akhirnya keputusan tim. Kamus Merriam-Webster: "java" = kopi, dari nama Pulau Jawa. Android memakai bahasa Java sebagai dasar aplikasinya; Minecraft dibuat dengan Java dan versi PC-nya disebut "Java Edition".** Alurnya: aplikasi di HP Android kamu ditulis pakai "bahasa Jawa"?! (3 detik pertama) → namanya Java, bahasa pemrograman terkenal dunia, dan namanya bukan kebetulan → nama awalnya Oak, ditolak pengacara → sambil ngopi, tim memilih "Java", sebutan Amerika untuk kopi... dari Pulau Jawa → bahkan Minecraft, game terlaris sepanjang masa, lahir dari bahasa ini → CTA follow.

**Catatan kejujuran:**
- "Bahasa Jawa" di hook ditulis dengan tanda kutip dan langsung dijelaskan di detik ±4: maksudnya bahasa pemrograman **Java** (nama Inggris untuk Jawa), bukan bahasa daerah Jawa. Teks layar "JAVA = JAWA" muncul di detik ±5 supaya tidak ada yang merasa dibohongi.
- VO bilang "**banyak**" aplikasi Android ditulis dengan Java, bukan "semua": sejak 2019 Google lebih menganjurkan Kotlin.
