Bahasa pemrograman Java ternyata dinamai dari kopi Jawa ☕ dan dipakai untuk banyak aplikasi Android sampai game Minecraft.

Bahasa ini dibuat tim Sun Microsystems di Amerika dan dirilis tahun 1995. Nama awalnya "Oak" (dari pohon ek di luar kantor pembuatnya), lalu "Green". Saat mau dirilis, pengacara melarang "Oak" karena sudah jadi merek dagang perusahaan lain. Dalam rapat mencari nama baru, salah satu anggota tim yang sedang minum kopi "Java" mengusulkan nama itu, dan tim sepakat memilihnya.

Di Amerika, "java" memang sebutan untuk kopi. Kata itu berasal dari kopi Pulau Jawa: VOC mulai menanam kopi di Jawa akhir 1600-an, mengirimnya ke Eropa sejak 1711, dan kopi dari Hindia Belanda sempat jadi pasokan kopi terpenting di dunia sampai disalip Brasil tahun 1840-an.

Fun fact: setiap file program Java diawali kode rahasia CAFEBABE. Dan bahasa yang sekarang dianjurkan Google untuk Android, Kotlin, juga dinamai dari sebuah pulau di Rusia, meniru Java yang namanya sama dengan Pulau Jawa.
