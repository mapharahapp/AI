# Caption #10: Pulau Run

**Judul (YouTube Shorts):** Pulau Kecil di Maluku Ini Pernah Lebih Berharga dari Manhattan 🏝️

**Caption (Instagram / TikTok / YouTube), salin dari sini:**

```
Pulau kecil di Maluku ini pernah dianggap lebih berharga dari Manhattan 🏝️🇮🇩

Abad ke-17, pala cuma tumbuh di Kepulauan Banda dan harganya selangit di Eropa. Inggris menguasai Pulau Run, padahal Belanda ingin memonopoli seluruh pala. Perang pun pecah.

Perjanjian Breda (31 Juli 1667) menetapkan: Belanda mempertahankan Pulau Run (juga Suriname), Inggris mendapat New Netherland, termasuk Manhattan yang kini jadi New York 🗽 Sekarang Manhattan dihuni sekitar 1,7 juta orang, Pulau Run kurang dari 2 ribu.
```
